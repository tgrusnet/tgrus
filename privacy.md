# Privacy Policy

## Telegram Client RU

**Last updated:** May 22, 2026

### 1. Information We Do Not Collect

This application does not collect, store, or transmit any personal user data to external servers.

### 2. Data Processing

- Messages are processed through official Telegram servers (telegram.org)
- No additional data collection is performed by this client
- User credentials are handled by official Telegram authentication system

### 3. Network Connection

This application includes built-in connection optimization for regions with network restrictions. All traffic is routed through official Telegram infrastructure.

### 4. Third-Party Services

This application does not integrate with third-party analytics, advertising, or tracking services.

### 5. Contact

For questions about this privacy policy, please contact through our project page.
